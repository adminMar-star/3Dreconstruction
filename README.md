# 融合图像拼接与特征提取的陶瓷轴承微损伤表征形貌三维重建研究
## 研究背景及意义
陶瓷轴承作为高端装备系统中的核心功能部件，在长期服役下的表现，直接决定装备的运行精度、可靠性与服役寿命，其在高端制造与特种装备领域的应用具有不可替代性。氮化硅(Si3N4)陶瓷的晶体结构具有典型的共价键三维网络特征，其基本结构单元为[SiN4]四面体，各四面体单元通过共用顶角的氮原子相互连接，形成六方晶系结构。这种独特的晶体构型赋予氮化硅陶瓷极强的耐腐蚀性、优异的热稳定性与良好的低热膨胀性，使其在众多陶瓷材料中脱颖而出，被誉为“陶瓷材料之王”。陶瓷凭借其优异的耐磨性能、环境适应性等性能，已成为航空航天、核能利用、军用航空战斗机等国家战略应用领域不可或缺的关键结构材料，在高端轴承制造中占据核心地位。
